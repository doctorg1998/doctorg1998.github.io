.NET 8 WPF · Microsoft Edge WebView2 · C# · PowerShell · Vanilla JS/CSS · JSON Schema v2.0 · Inno Setup · GitHub Actions

The problem

Mid-match, players alt-tab out to look up builds, perk thresholds and loadouts. That breaks focus and costs time, and most overlay tools solve it with invasive memory hooks that anti-cheat systems flag.

Nexus runs as a single dark Windows 11 window. It notices which game is running, switches context on its own, and shows builds that adapt to the player's current level, without touching game memory.

How I built it

I directed Claude Sonnet and Google Gemini as coding and diagnostic agents instead of hand-writing UI boilerplate and Win32 plumbing. I set the architecture constraints, versioned the data schema, and required every change to pass automated verification gates before I accepted it.

Scoped loopback TLS, no global bypass

Riot's local servers use a request-scoped certificate callback instead of a global ServicePointManager override, so all external HTTPS stays strictly validated.

Credential scrubbing

Ephemeral auth strings from the Riot lockfile are cleared in finally blocks, and Basic … / riot:… tokens are redacted before anything reaches the error log.

Allowlisted message bridge

The host-to-UI bridge checks origin, caps payloads at 200 KB, validates JSON shape and allows only known message types, covered by negative security tests U03, U06 and T23.

End-to-end coverage

Browser tests cover all 5 detection states (Idle, Client Open, Priority Yielding, Champ Select, In-Game), build duplication with 5-second undo, tag filtering and the 375×812 Compact HUD.
